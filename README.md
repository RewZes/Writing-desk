# Writing Desk

A writing app for notes and books — on Windows and Android, kept in sync between them.

## Download

Open **[Releases](../../releases/latest)** and pick the file for your device:

| File | What it is |
|---|---|
| `WritingDesk-Setup-x.y.z.exe` | **Windows — first install.** Choose *Install on this computer* or *Portable*. |
| `WritingDesk-Update-x.y.z.exe` | **Windows — update** an existing copy (small download). Your writing is kept. |
| `WritingDesk-x.y.z.apk` | **Android** — install, or install over the previous version to update. |

The app checks this page once a day and tells you when a new version is out (Settings → Updates → *Check now*).

## Notes

- **Windows says "Windows protected your PC"?** The setup isn't digitally signed. Click **More info → Run anyway**.
- **Android asks about unknown apps?** Allow installs from your browser or file manager for this one time.
- **Your writing never leaves your devices**, except for the cloud sync you set up yourself in the app.
- **Automatic backups:**
  - Windows: `Documents\Writing Desk Backups` (portable copies: the `data\Backups` folder).
  - Android: `Documents/WritingDesk`.
