First release on GitHub.

**Windows**
- New in this version: a proper setup. Choose **Install on this computer** or **Portable**. You get shortcuts, an uninstaller, and automatic daily backups in `Documents\Writing Desk Backups`.
- On its first start, the new app brings over the writing from the old Writing Desk folder app.
- From now on, updates come as the small **WritingDesk-Update** file.

**Android**
- Install over the current app; your writing stays.

**Both**
- The app now checks this page once a day and tells you when a new version is out (Settings → Updates).

**Which file?**
- `WritingDesk-Setup-1.58.0.exe` — Windows, first install (or if the update file asks for it).
- `WritingDesk-Update-1.58.0.exe` — Windows, update an existing copy.
- `WritingDesk-1.58.0.apk` — Android.
